# ЧистоБалт — сайт клининговой компании в Калининграде

Многостраничный статический сайт: главная, услуги и цены, информация о компании, контакты и политика обработки персональных данных. Без сборки и зависимостей — чистые HTML, CSS и JavaScript.

## Структура

```
chistobalt/
├── index.html        — главная страница
├── services.html     — полный прайс-лист (26 услуг)
├── about.html        — о компании, география, принцип расчёта цены
├── contacts.html     — контакты и форма заявки
├── privacy.html      — политика обработки персональных данных
├── styles.css        — все стили
├── script.js         — меню, маска телефона, форма, cookie
├── assets/
│   ├── favicon.svg
│   └── hero-line.svg — локальная иллюстрация
└── README.md
```

## Как открыть

Просто откройте `index.html` в браузере. Либо запустите локальный сервер:

```powershell
cd chistobalt
python -m http.server 8080
```

и перейдите на `http://localhost:8080`.

## Что заменить перед публикацией

1. **Телефон** — сейчас везде стоит заглушка `+7 (000) 000-00-00` и ссылка `tel:+70000000000`. Замените во всех пяти HTML-файлах.
2. **Электронная почта** — заглушка `info@chistobalt.ru`. Замените на реальный адрес.
3. **Данные оператора персональных данных** — в `privacy.html`, раздел 14. Сейчас оставлены пустые поля: наименование организации или ИП, ИНН, ОГРН/ОГРНИП, адрес. Без этих данных политика не готова к публикации.
4. **Домен** — если он отличается от `chistobalt.ru`, проверьте упоминания в текстах и мета-тегах.
5. **Фотографии** — сейчас используется только локальная SVG-иллюстрация `assets/hero-line.svg`. Фотографии с Avito подключить не удалось: площадка ограничивает автоматический доступ. Добавьте свои снимки в `assets/` и замените иллюстрацию на `<img>`.

## Цены

Прайс-лист составлен строго по данным заказчика: 26 услуг, указанное время, цена и примечание. В `services.html` сохранены формулировки «от», «цена договорная», «за м²», «за этаж», «за день» и пометки «Рыночная цена» / «Стоит уточнить».

Если цены изменятся, правьте только таблицу в `services.html`. На главной странице шесть популярных позиций продублированы вручную — их нужно синхронизировать.

## Форма заявки

Форма проверяет имя, телефон и обязательное согласие на обработку персональных данных, после чего показывает сообщение об успешной отправке. **Данные никуда не отправляются.**

Варианты подключения:

- **Formspree / Getform** — добавьте `action` и `method="post"` в `<form id="leadForm">`, уберите `event.preventDefault()` или отправляйте через `fetch`.
- **Свой backend** — в `script.js` найдите комментарий `Здесь подключается ваш обработчик` и замените `setTimeout` на `fetch('/api/lead', ...)`.
- **Telegram-бот** — отправляйте данные на свой webhook.

Перед сбором данных через форму на сайте должны быть опубликованы политика обработки ПД и согласие — они уже включены.

## Персональные данные и cookie

- Чекбокс согласия обязателен — без него форма не отправится.
- Ссылка на политику открывается в новой вкладке.
- Cookie-баннер сохраняет выбор в `localStorage` (`chistobalt_cookie_accepted`).
- Политика описывает состав данных, цели, сроки хранения, передачу третьим лицам, права субъекта и порядок отзыва согласия.

## Технические детали

- Без сборки и внешних библиотек.
- Шрифты системные: Georgia для заголовков, Segoe UI для текста. Внешние шрифты не загружаются.
- Адаптив: сетки перестраиваются под планшет и телефон, есть мобильное меню.
- **Тёмная и светлая темы** — переключатель в шапке сайта, выбор сохраняется в `localStorage`, учитывается системная предпочитаемая цветовая схема (`prefers-color-scheme`).
- Анимации минимальные; при `prefers-reduced-motion` отключаются.
- Цены не рассчитываются на сайте: калькулятор убран, чтобы не выдумывать формулы и не обещать сумму, которую нельзя подтвердить.

## Дизайн

Оформление и тексты оригинальные. Референс использован только как ориентир по структуре клинингового сайта; чужие тексты, фотографии и код не копировались. История компании, имена владельцев и сотрудников, отзывы и гарантии на сайте не публикуются — этих данных у заказчика не было.
